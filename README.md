# 人生を経営するための行動管理システム Backend
## 開発背景
2026年6月12日に会社を辞めた筆者が、個人で自律的なWEBクリエイターとしての目標を達成するために、AIと共同して制作しました。
## 概要
このアプリケーションには、「社長が会社を経営するように、個人で会社に依存せずに自分の人生を経営しよう」という意図が込められています。
自律的なWEBクリエイターとして重要なのは、以下の4点です。
* 営業（家計を支えるための収益を得るための活動）
* 計画（顧客のどんな問題をどのように解決するかという現実的なプラン）
* 開発（顧客との約束を果たすための活動）
* 健康（自律的なWEBクリエイターとしての自分を最高の状態に整えるための活動）


## 本リポジトリのシステムについて
Django REST Frameworkを利用し、4つの視点から管理するタスクデータを提供します。
[React Frontend](https://github.com/ki-hi-ro/react_todo)と連携し、タスクの登録・取得・更新・削除を行うためのREST APIを構築しています。

## API一覧

### タスク一覧取得

```http
GET /api/tasks/
```

登録済みタスクを取得します。

---

### タスク詳細取得

```http
GET /api/tasks/{id}/
```

指定したタスクを取得します。

---

### タスク登録

```http
POST /api/tasks/
```

新しいタスクを登録します。

---

### タスク更新

```http
PUT /api/tasks/{id}/
PATCH /api/tasks/{id}/
```

タスクを更新します。

---

### タスク削除

```http
DELETE /api/tasks/{id}/
```

タスクを削除します。

---

## データモデル

### Task

| 項目          | 型       | 説明   |
| ----------- | ------- | ---- |
| id          | Integer | ID   |
| title       | String  | タスク名 |
| description | Text    | 詳細説明 |
| category    | String  | カテゴリ |
| completed   | Boolean | 完了状態 |
| deadline    | Date    | 期限   |
